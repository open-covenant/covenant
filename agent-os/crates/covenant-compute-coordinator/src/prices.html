How to read this

Each dot is one daily average for a GPU model and provider. Bars show that day’s minimum and maximum. Averages are weighted by GPU time. Missing days stay empty; quotes in USD and charges in USDC are kept separate.

Historical coverage begins when this release starts recording source data. The provider market is sampled within a fixed per-model cap; it is not a census of provider capacity. Older sessions without GPU and price metadata are excluded. A day with no samples is not a zero price.
