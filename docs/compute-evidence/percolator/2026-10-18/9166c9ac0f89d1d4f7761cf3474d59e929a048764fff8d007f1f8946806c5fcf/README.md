## Verify without buyer credentials

Use the archived inventory and source bundle, Git, Python 3, and a separately built Rust verifier. No buyer identity, coordinator API access, or paid execution is needed to verify the evidence. Building the verifier may download public Cargo dependencies; its verification run is offline.

1. Obtain the public Covenant repository and check out canonical merge `983172ddd04ac2de70136125e2088f22c6edf505` (or the actual build commit `d997bb6436569d8dc96f963aaf72259b92ccb5ba`); the verifier input equivalence is recorded separately.
2. Generate the isolated helper project, preserve the archived lockfile, and build:

   ```sh
   python3 build-verifier.py --checkout /path/to/covenant --project /tmp/receipt-verifier
   cp verifier.Cargo.lock /tmp/receipt-verifier/Cargo.lock
   cargo build --locked --manifest-path /tmp/receipt-verifier/Cargo.toml
   ```

3. Verify the complete archive and the source-to-patch-to-integration mapping:

   ```sh
   python3 verify-archive.py --archive . --verifier /tmp/receipt-verifier/target/debug/verify-public-receipt
   python3 verify-followup.py --archive . --checkout /path/to/covenant
   ```

`verify-archive.py` checks inventory hashes, exact original commit bytes, signed snapshot tree equality, source copies, both signed envelopes and receipts, output hashes, parent/child bindings, and acceptance of the final returned patch. `verify-followup.py` applies only patches to a temporary Git index; it does not execute the archived source. It verifies the paid and integrated file copies and compares the final component tree with the independently obtained Covenant checkout.

`verifier-d997-build.json` records the actual local verifier build commit, compiler, binary and lockfile hashes. Its 17 archive tests and three signed-child tamper rejection controls are local validation, not additional paid work. Both signed execution windows expired before local public staging. `publication-review.json` records the exact inventory reviewed for privacy and expiry; it is an agent review record, not another operator signature.
